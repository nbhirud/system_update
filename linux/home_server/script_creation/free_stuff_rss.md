## ✅ **Craigslist Toronto**

All free listings:

* `https://toronto.craigslist.org/search/zip?format=rss`

Want keyword filters? Add `&query=KEYWORD`

> Examples:

* `https://toronto.craigslist.org/search/zip?query=fan&format=rss`
* `https://toronto.craigslist.org/search/zip?query=tv&format=rss`
