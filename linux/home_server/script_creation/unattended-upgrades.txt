# Allow More Than Just Security Updates (Use with Caution!)
# By default, unattended-upgrades only installs security updates (-security origin). If you want to automatically install all updates (including regular bug fixes and new features from the main repositories), you can uncomment more origins.

sudo nano /etc/apt/apt.conf.d/50unattended-upgrades
# Find the Unattended-Upgrade::Allowed-Origins section:
```
Unattended-Upgrade::Allowed-Origins {
        "${distro_id}:${distro_codename}";
        "${distro_id}:${distro_codename}-security";
        // Extended Security Maintenance; doesn't necessarily exist for
        // every release and this system may not have it installed, but if
        // available, the policy for updates is such that unattended-upgrades
        // will also automatically install from there.
        "${distro_id}ESMApps:${distro_codename}-apps-security";
        "${distro_id}ESM:${distro_codename}-infra-security";

        // Uncomment to enable updates from the main repository (non-security)
        // "${distro_id}:${distro_codename}-updates";

        // Uncomment to enable updates from the proposed repository (less stable)
        // "${distro_id}:${distro_codename}-proposed";

        // Uncomment to enable updates from the backports repository (newer features)
        // "${distro_id}:${distro_codename}-backports";
};

```
# Recommendation: For a home server, it's generally safest to stick to only security updates (-security origin, which is enabled by default). Uncommenting "${distro_id}:${distro_codename}-updates"; will get you more general bug fixes and minor package updates, which is often acceptable for a home server, but increases the chance of minor issues. Avoid -proposed and -backports for a production-like home server unless you know exactly what you're doing.
